# Family Genealogy Register — Source-Faithful Markdown

## Purpose

This file organizes the genealogy recorded in **`ከሰተ-ብርሃነ.pdf`** so it can later be used as the source for building a family-tree website. It is a transcription and organization aid, not a claim that every relationship has already been verified.

## Rules for anyone importing these records

1. **Do not merge people by name.** Each occurrence of a name may represent a different person. Create a separate provisional person record for each occurrence unless the source or family verification proves two occurrences refer to the same person.
2. **Preserve the name exactly as written here.** Keep Tigrinya/Ge'ez characters, spaces, punctuation, titles, and spelling variants. Do not silently normalize spelling.
3. **Only create a parent/child or partner relationship when the source wording explicitly supports it.** A section headed `X ዝወለዶም` lists children attributed by the source to X. A phrase of the form `X ናብ Y ... ኣትያ ዝወለደቶም` is preserved as a source relationship statement; do not reinterpret the cultural/legal meaning without confirmation.
4. **Keep ambiguous name groups unassigned.** If names appear without a clear heading or continue across a page boundary, record them as a source block with its page number and mark the relationship as `needs_review`; do not guess a parent.
5. **Keep source location.** Every imported record and relationship should retain the PDF page and the exact heading/source phrase that supports it.
6. **Do not invent missing people or fill blank sections.** Empty or incomplete source statements remain incomplete and must be flagged for review.
7. **Keep an audit trail.** A later reviewer should be able to compare every person and relationship in the website with this Markdown file and the original PDF.

- **Explicit relationship block**: a relationship phrase in the source is followed by the names listed beneath it.
- **Unlabelled/source-order block**: names appear in the source but the visible text does not unambiguously identify their parent or relationship. Keep them as separate records pending review.
- “Continued from the previous page” is only a note about source layout, not permission to assume a relationship if the parent label is not explicit. When uncertain, treat the block as `needs_review`.
